# Task 1.4 — node inspector: click a node, see everything about it

> Written by Claude, executed by Qwen. **Start only after 1.3h is reviewed**:
> this card uses its `sizingLabel` (`format.ts`) and `verified_*` fields.
> Pure frontend; no engine or API change.

## Goal
Click, Enter or Space on a topology node opens an accessible dialog with that
node's config, what the last run measured (the verified label from 1.3h),
its findings and its "Fix it" change. Esc closes it and focus returns to the
node.

## Evidence (checked 2026-10-10)
- Per node, `summary()` has: config (role, ×N, service time, rate),
  `component_sizing` (mean/p95 util, p95 queue, verified label and size),
  `timeseries.per_component` (peak util and queue), `findings[].node`,
  `suggestions[].node`.
- **Not per node:** failures, retries, p95 contribution: only run-wide totals
  exist. The roadmap listed them; they are left out (an engine follow-up).
- `Modal.tsx` already gives the dialog contract (focus trap, Esc, focus
  return) and `FixDiffPanel` already applies a single suggestion with
  `onApply([suggestion])`. Reuse both.
- The cost of this run for one node is under $0.01 on the demo (60 s), so
  the dialog shows the monthly price instead, using Fix it's formula
  (`rate × capacity × 720`): db at ×3 is $130, the same as its +$130 fix.

## Steps
1. **New `web/src/core/lib/nodeInspector.ts`** (pure, no React):
   - `NodeMeasurement { status: SizingStatus; recommended: number; meanUtil; p95Util; p95Queue: number; peakUtil: number | null; peakQueue: number | null }`
   - `NodeInspection { name; role: ComponentRole; capacity; serviceTime; costPerHour: number | null; monthlyCost: number | null; measured: NodeMeasurement | null; remeasure: "running" | "unmeasured" | null; findings: Finding[]; fix: Suggestion | null }`
   - `inspectNode(name, config: SimulationConfig, result: SimulateResponse, stale = { names: [], running: false }): NodeInspection | null`:
     - `null` when `name` is not in `config.topology.nodes`.
     - `remeasure`: `"running"` / `"unmeasured"` when `name` is in `stale.names` (by `stale.running`), else `null`.
     - `measured`: `null` when re-measured or the node has no `component_sizing`; else `status` / `recommended` from `sizingLabel(info)`, the three utilization/queue fields from `info`, and `peakUtil` / `peakQueue` = the max of `result.timeseries[*].per_component[name].utilization` / `.queue_length` (`null` when there are no ticks for it).
     - `monthlyCost`: `cost_per_hour × max_capacity × 720` (a module constant `HOURS_PER_MONTH = 720`, citing `rightsize.py::_HOURS_PER_MONTH`); `null` with no rate. Computed even while re-measured.
     - `findings`: `summary.findings` with `node === name`, in order; `[]` while re-measured.
     - `fix`: the entry of `pendingSuggestions(config, summary.suggestions ?? [])` for this node, or `null`.
2. **`topologyView.ts` `TopologyDiagramProps`:** add `onOpen?: (name: string) => void`, with a doc comment that it must be stable (the diagram is `memo`).
3. **`TopologyDiagram.tsx`:** destructure `onOpen`, pass it to each `NodeShell`. In `NodeShell` (not `NodeBody`):
   `role={onOpen ? "button" : "group"}`, `aria-haspopup={onOpen ? "dialog" : undefined}`,
   `cursor: "pointer"` in `style` when `onOpen`, `onClick` → `onOpen(view.name)`, and `onKeyDown`:
   Enter or `" "` → `event.preventDefault(); onOpen(view.name)`. All of these `undefined` without `onOpen`.
4. **New `web/src/core/components/NodeInspector.tsx`** (`"use client"`), props
   `{ inspection, onClose, onApply: (s: Suggestion[]) => void, isPending }`, inside
   `<Modal open onClose labelledBy={TITLE_ID} className="max-w-xl">`, laid out like `VerdictReportModal`:
   - Header: the name (`font-mono`, the `h2` with `TITLE_ID`), `role` with `_` → space, `· ×N`; a close button `aria-label="Close inspector"` (same classes and ✕ icon as the report's).
   - **Sizing:** when `measured`, the verdict word with `SeverityIcon` in `SEVERITY_TEXT[sizingSeverity(status)]`, plus ` · ×N → ×M` when `recommended !== capacity`; then a `<dl>` grid (`grid-cols-2 sm:grid-cols-3`) of six facts: Mean utilization `fmtPct(…,1)`, P95 utilization `fmtPct(…,1)`, Peak utilization `fmtPct(…,0)` or `n/a`, P95 queue `toFixed(1)`, Peak queue `toFixed(0)` or `n/a`, Service time `fmtSeconds(…,2)`. Otherwise one dim line: "Measuring the new size…" / "Not measured at this size yet: run again to see it." / "No measurement for this node yet."
   - **Cost:** two facts: "Per hour, per slot" `fmtMoney(costPerHour)` or "no rate"; `Per month, 24/7 at ×N` `fmtMoney(monthlyCost)` or "no rate".
   - **Findings** (only when any): `findingKeys(findings).map((key, i) => <FindingCard key={key} finding={findings[i]} />)`.
   - **Fix** (only when `fix`): `×current → ×proposed` (mono, semibold) and `fix.reason`, and the accent "Apply & re-run" button (same classes as `FixDiffPanel`'s) → `onApply([fix]); onClose();`, `disabled={isPending}`, label "Running…" while pending.
   - Each fact is `<div className="rounded-lg border border-line bg-surface-1 px-3 py-2"><dt className="text-[11px] text-ink-dim"/><dd className="mt-0.5 font-mono text-sm text-ink"/></div>`. Section labels as in `VerdictReportModal`.
5. **`page.tsx`:** `useState<string | null>(null)` → `[inspected, setInspected]`; `const inspection = inspected && result ? inspectNode(inspected, config, result, stale) : null;`. Pass `onOpen={setInspected}` to `TopologyDiagram` (the setter is stable: no `useCallback`). Render `{inspection ? <NodeInspector inspection={inspection} onClose={() => setInspected(null)} onApply={applyAndRerun} isPending={isPending} /> : null}` right after the diagram inside the Topology panel.
