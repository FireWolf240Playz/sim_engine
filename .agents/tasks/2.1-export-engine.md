# Task 2.1 — export center: the engine (request log + three formats)

> Roadmap 2.1, first of three cards: **2.1** engine (this), **2.1b** API + CLI,
> **2.1c** web export menu. First-of-its-kind, so it is not a replication card:
> the design below is decided, build it literally.

## Goal
One run can be written out as a per-request CSV, a replayable JSON and an
Excel workbook, by pure functions the CLI and the API both call.

## Measured before this card
- Per-request rows are **not** in `summary()`; they are the collector's
  `RequestRecord`s. Retries per request and the node a failed request gave up
  at were not recorded anywhere.
- 200,000 requests (the API's limit) → a 15 MB CSV, 75 bytes a row, 0.85 s to
  build after a 4.8 s run. No streaming needed at this size.
- openpyxl stores a string starting with `=` as a **formula** (`data_type "f"`).
- openpyxl stamps the save time into the file: equal runs give equal cells,
  not equal bytes. Do not try to make the bytes equal.

## Design (decided)

### `MetricsCollector.request_log() -> list[dict[str, Any]]`
One plain dict per recorded request, sorted by arrival time (`start`, stable):

| key | value |
|---|---|
| `request_id` | str |
| `t` | arrival time, seconds |
| `end` | finish time (the horizon for an overdue request) |
| `latency` | `end - t` |
| `service_time` | sum of `component_times` |
| `wait_time` | `max(0.0, latency - service_time)`: queueing and retry backoff |
| `outcome` | `"completed"`, `"failed"` or `"overdue"` |
| `sla_met` | bool |
| `retries` | int, this request's own timeout retries |
| `cache_hit` | bool or None |
| `failed_at` | name of the node whose slot it never got, else None |
| `path` | list of node names served, in order (`component_times` keys) |

Plain Python types only (`json.dumps(row, allow_nan=False)` must work).

### Engine
- `_use_component` already calls `collector.record_retry(name)` once per
  retry. Count the same events per request (thread a small mutable counter
  from `serve_request` down through `_walk`; these are private methods, change
  their signatures freely). **No new random draw**: the test pins
  `requests == 72, total_retries == 134` for a seeded run.
- `failed_at` = `ComponentTimeoutError.component_name` when that is why the
  request failed; None otherwise (interrupt, success, overdue).

### `sim_core/exports.py` (pure: no `sim_core` import; `openpyxl` imported inside `to_xlsx`)
- `CSV_COLUMNS`, `XLSX_SHEETS`, `PER_NODE_COLUMNS`, `FINDINGS_COLUMNS` — tuples, values in the test.
- `spreadsheet_safe(text) -> str` — prefix `'` when the text starts with one of `= + - @ \t \r`.
- `to_csv(request_log) -> str` — `csv` module on `io.StringIO(newline="")`,
  default `\r\n` line ends. `t` to 6 decimals, the three `_ms` columns to 3
  (`f"{x:.6f}"` / `f"{x * 1000:.3f}"`), `failed`/`sla_ok`/`cache_hit` as
  `1`/`0` (blank `cache_hit` when None), `path` joined with `>`. Every text
  cell (`request_id`, `outcome`, `failed_at`, `path`) through `spreadsheet_safe`.
- `to_json(summary, config, *, seed=None) -> str` — `{"eleven_export":
  {"version": 1, "format": "json"}, "seed", "config", "summary"}`, `indent=2`,
  trailing newline, `allow_nan=False` after replacing every non-finite float
  (at any depth) with `None`. Inputs are not mutated.
- `to_xlsx(summary, config, *, seed=None) -> bytes` — three sheets:
  - **Summary**: header `("Metric", "Value")`, then one row per metric. The
    labels the test reads are required; add the rest of the headline numbers
    (P50/P99, avg latency, retries, unfinished/overdue, cache hit rate, cost
    base/metered, yearly cost, verdict headline) in a sensible order.
  - **Per-node**: header `PER_NODE_COLUMNS`, one row per `config["topology"]["nodes"]`
    entry in config order, values from the node dict and
    `summary["component_sizing"][name]` / `cost_breakdown_by_component`.
    A missing value is an empty cell (None), never `0`.
  - **Findings**: header `FINDINGS_COLUMNS`, one row per finding.
  - Numbers stay numbers. **Every string cell is forced to text** (set
    `cell.data_type = "s"` after assigning) so nothing is stored as a formula;
    do not alter the text itself in the workbook. Bold header row, frozen
    first row, reasonable column widths.
- `ExportFormat` (NamedTuple: `name`, `label`, `extension`, `media_type`,
  `tier`, `uses_summary`) and `EXPORT_FORMATS` in the order csv, json, xlsx.
- `render_export(fmt, *, summary, config, request_log, seed=None) -> bytes` —
  the one dispatch; unknown format → `ValueError("unknown export format 'pdf'; expected one of: csv, json, xlsx")`.

## Constraints
- Pydantic holds config, SimPy holds state: `exports.py` sees plain dicts only.
- Full type hints; `from __future__ import annotations`; docstrings that say why.
- `summary()`'s keys and values do not change. Every existing test stays green.
- No dependency beyond `openpyxl`.

## Out of scope
- The API route and the CLI flag (card 2.1b). The web UI (card 2.1c).
- Per-node columns in the CSV, the path of an overdue request, streaming.
- Tier enforcement: `tier` is a label here; the 402 lands with auth (roadmap 2.2).

### One addition beyond the card
- In the workbook only, control characters XML cannot carry (`\x00-\x08`, `\x0b`, `\x0c`, `\x0e-\x1f`) are dropped from string cells. openpyxl raises `IllegalCharacterError` on them, so a node named `bad\x01name` would otherwise fail the whole export. All other text is stored unchanged, as a text cell.

### Notes for review
- The retries of a request that is still in flight at the horizon are counted in `total_retries` but belong to no row (an overdue row has `retries == 0`, a merely unfinished request has no row). The sum of the `retries` column equals `total_retries` only when nothing is unfinished, which is what the test arranges.
- An xlsx file has one number type: a float with an integral value (`sla_target` 1.0, a score of exactly 0.0 or 100.0) reads back from openpyxl as an `int`. The cells are numeric either way.
- `mypy` is not installed in `venv/`, so the new module was not type-checked by a tool.
- `ruff check` on `metrics.py` / `engine.py` reports the `Dict`/`List`/`Optional` style those files already used; the new lines follow that surrounding style and the files were not reformatted.
