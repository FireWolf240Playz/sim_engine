# Task 3.4 — timeline replay: scrub a finished run

> Roadmap 3.4. Needs 3.2 (`LiveStage`, `PlaybackBar`, `lib/playback.ts`).
> Built right after 3.2 because it is the same component; 3.3 can come before or after.

## Goal
On a finished run the user drags a scrubber, steps tick by tick, or jumps to
"where it broke", and the diagram, the feed and a cursor on the latency
chart all show that moment. Nothing is simulated again.

## Decided, and why
- **No backend work.** The roadmap asks for a compact `timeline` array in
  the response. Card 3.1 already put everything replay needs into each tick
  (`arrived`, `completed`, `failed`, live `capacity`, `edge_flow`), and the
  page already holds the run's ticks, chaos events and feed lines from the
  stream. Replay reads those.
- **Replay is 3.2's playback with a handle on it**: same clock, same frame,
  same components, a different way to move `position`.

## Design (decided)

### `lib/replay.ts`
- `stepTick(playback, ticks, 1 | -1)` → the next tick after / the last tick before `position`, paused; stays put at either end.
- `replayMarks(lines)` → `[{t, kind, text}]`: every `incident_start` and the **first** `failures` line, in order.
- `breakingMoment(lines)` → the time of the first `failures` line, else the first `saturated`, else the first `incident_start`, else `null`.
- `positionFraction(position, duration)` → 0..1, for placing the thumb and the marks.

### `PlaybackBar`
- A scrubber across the bar: `<input type="range">` from 0 to the run's
  duration, step = the tick interval, value = `position`; dragging calls
  `seek` (which pauses). Ticks not yet received are out of reach (`seek` clamps to the live edge).
- Marks on the track at `positionFraction(mark.t, duration)`: a small tick
  in the crit colour, `title={mark.text}`, clicking seeks there.
- A `Jump to where it broke` button, shown when `breakingMoment` is not null; it seeks there.
- Keys while the bar has focus: Space toggles play, ← / → `stepTick`, Home / End seek to 0 / the edge.
- The time label gains the tick's own time while paused (`t=62s / 120s`).

### The chart cursor
- `LiveStage` reports the current tick time upward (`onCursor(time | null)`)
  **only when the frame index changes** (a few times a second, never per
  animation frame), and takes `seekTo` requests from the page.
- `TimelineChart` gets `cursor?: number | null` (a vertical `ReferenceLine`
  at that time, accent colour) and `onSeek?: (time: number) => void` (a
  click on the plot seeks to the clicked time). Without the props it is unchanged.

## Constraints
- **Zero requests while scrubbing or replaying**: no `api.*` call anywhere in this path.
- No new dependency; no new `memo`; tokens for every colour.
- `positionFraction` and the range input must agree, so a mark sits where the thumb stops.
