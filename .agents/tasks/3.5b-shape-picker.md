## Design (decided)

### `lib/trafficShape.ts`
- `TRAFFIC_SHAPES`: `flat` / `ramp` / `diurnal` / `black_friday`, labels
  `Flat`, `Ramp`, `Business day`, `Black Friday`, each with a one-sentence `blurb`.
- `DEFAULT_SHAPE_PEAK = {ramp: 3, diurnal: 3, black_friday: 5}`.
- `shapeMultiplier(shape, u, peak)`, `rateAt(traffic, t)` (zero outside the
  window, a spike overrides, `start_time` respected), `shapePeak(traffic)`,
  `peakRps(traffic)`: the engine's formulas, pinned with the engine's numbers.
- `withShape(traffic, shape, peak?)` → a new traffic block. `flat` removes
  **both** `shape` and `shape_peak`: the engine refuses a peak on a flat
  pattern, and picking Flat again must give back exactly the config the
  demo's scores were calibrated on. Without `peak`, no `shape_peak` key is
  written (the engine's default applies).
- `shapePath(shape, peak, width, height, scaleMax = peak)` → an SVG path of
  49 points (`M… L…`, at most two decimals), `y = height × (1 − multiplier / scaleMax)`.

### The picker
- A `Traffic` row in the same bar as `Incident` (same heading style, same
  segmented-control look as `IncidentPicker`), or directly under it when
  there is no room: four options, each a small SVG of its curve
  (`shapePath(shape, defaultPeak, 56, 20, 5)`: one scale, so Black Friday
  visibly towers over a flat day) above its label.
- Under the control, one line for the selected shape: its blurb and the
  numbers, e.g. `A normal day, then a surge. 2.0 rps quiet, peaks at 10.0 rps.`
  (`peakRps` of the active config).
- `role="radiogroup"`, each option a radio; disabled while a run is pending.
- Selecting calls `setTrafficShape(shape)`: the active config's `traffic`
  becomes `withShape(traffic, shape)`. It does not start a run (like the
  incident picker) and does not reset the change log, the label or the injected failures.
- The stroke uses a token (`stroke-accent` selected, `stroke-ink-dim` otherwise); no hex.

### Carried through
- Export, Copy YAML and "Apply & re-run" send the config as it is, so the
  shape travels with it; check that Copy YAML's output contains `shape: black_friday` once selected.
- The API budget counts the shape (3.5). A refusal for a config that is now
  too large arrives as the engine's sentence through the existing error path.
