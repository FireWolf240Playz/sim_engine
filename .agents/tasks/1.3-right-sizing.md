## Goal
Every `summary()` carries `suggestions`: a deterministic list of
`max_capacity` changes that move undersized nodes up and oversized nodes down,
and the CLI prints them as a "Fix it" block.

## Changes to your plan (decided 2026-10-08; these override it)
1. **No top-level API key. Do not touch `api/`.** A top-level `suggestions`
   key breaks `tests/test_profile.py::test_api_single_run_key_set_unchanged`
   (1.1's byte-identical contract). Put the list in `summary()` instead, the
   same way `findings` rides along. It then reaches the CLI, the single-run
   API, every multi-seed run, and the typical summary with zero API code.
   Release your `api/routes/simulate.py` + `api/schemas.py` lock.
2. **Undersized does NOT use `recommended_capacity`.** It is the p99 of
   in-use + *queued* demand, and the queue backlog dominates it: the
   default config with `app-worker` at 2 slots reads 138, and the healthy
   6-slot worker reads 62. Rule:
   `proposed = max(current + 1, ceil(current * mean_util / 0.8))`.
3. **Oversized means `status == "oversized"`** (util ≤ 0.5 in `metrics._verdict`),
   not util < 40%. `proposed = max(1, floor(current * 0.75))`. Emit only if
   `proposed < current` and `mean_util * current / proposed <= 0.8`.
4. **`est_monthly_delta = cost_per_hour * (proposed - current) * 720`**, or
   `None` when the node has no rate (missing or 0). Not a rescale of
   `cost_breakdown_by_component`: that includes metered cost, which does not
   scale with capacity.
5. **Signature:** `build_suggestions(nodes, summary)`, where `nodes` is an
   iterable of node *dicts* (`name`, `max_capacity`, `cost_per_hour`). Like
   `findings.py`, the module imports nothing from `sim_core` except, at most,
   `HOURS_PER_MONTH` from `score.py`.
