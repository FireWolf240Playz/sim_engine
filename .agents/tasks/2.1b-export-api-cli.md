# Task 2.1b — export center: `POST /export` and `--export`

> Roadmap 2.1, second of three cards. Needs card 2.1 (`sim_core/exports.py`) done.

## Goal
A run can be downloaded from the API and written by the CLI in any of the
three formats, through `sim_core.exports.render_export` and nothing else.

## Decided, and why
- **The API re-runs.** It keeps no run, so an export names its run by config
  (with seed) + playbook and the server simulates it again; the engine is
  deterministic, so the file is the run the caller saw. A `run_id` replaces
  the re-run when the run store lands (roadmap 3.1); keep the request model
  easy to extend with it.
- **A config without a seed is refused (422):** the server would otherwise
  export a different run than the one on screen.
- **CSV skips the Fix-it plan** (`run(suggest=False)`): the plan costs seconds
  on large topologies and the request log does not need it
  (`EXPORT_FORMATS[fmt].uses_summary`).
- **The CLI never simulates twice:** it exports from the simulator it just ran.
- **Tier is a label, not a gate.** `GET /export/formats` reports it so the UI
  can show it; the 402 lands with auth (roadmap 2.2).

## Design (decided)

### `POST /export`
Body `{config: SimulationConfig, format: "csv"|"json"|"xlsx", playbook?: str}`.
1. unknown playbook → 404 `unknown playbook: 'nope'` (same text as `/simulate`);
   a playbook that cannot apply → 400, as `/simulate` does.
2. `config.seed is None` → 422, detail a sentence containing `seed` and `re-run`.
3. `check_budget(config, runs=1)`.
4. `simulator = CloudSimulator(config)`; `summary = simulator.run(suggest=fmt.uses_summary)`.
5. `render_export(name, summary=summary, config=config.model_dump(mode="json"),
   request_log=simulator.collector.request_log(), seed=simulator.seed)`.
6. `fastapi.Response(content=..., media_type=fmt.media_type, headers={"Content-Disposition":
   'attachment; filename="eleven-<playbook or run>-seed<seed>.<ext>"'})`.
   `config` here is the config **after** the playbook was applied.

`format` is a `Literal` of the registry's names, so an unknown one is FastAPI's
own 422 (it lists the allowed values).

### `GET /export/formats`
`{"formats": [{name, label, extension, media_type, tier}, ...], "count": 3}` in registry order.

### CLI
- `run` and `demo` gain `--export FORMAT [FORMAT ...]` (`nargs="+"`,
  `choices` = the registry's names) and `--export-base PATH` (default
  `eleven_export`). Files are `<base>.<ext>`; create the parent directory.
- Write bytes (`Path.write_bytes(render_export(...))`), never text mode: text
  mode on Windows turns the CSV's `\r\n` into `\r\r\n`.
- Print `Export written to: <path>` per file; in a `--seeds N` run export the
  typical run and print `Export (typical run, seed <seed>) written to: <path>`.
- The summary in the exported JSON is the one already printed and written to
  `--json` (do not run again).
